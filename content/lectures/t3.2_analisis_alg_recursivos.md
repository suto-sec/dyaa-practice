## Introducción
### Análisis de algoritmos recursivos
- La matemática necesaria son las relaciones de recurrencia (ecuaciones en diferencias, o simplemente recurrencias): expresiones matemáticas recursivas.
$$T(n)=\begin{cases}3 & n=0\\ 5+T(n-1) & n>0\end{cases}$$
- Resolver una recurrencia = dar una fórmula no recursiva equivalente: $T(n)=5n+3$
- Dos formas de resolverlas: expansión de recurrencias; "método general".

## Análisis de eficiencia en tiempo: expansión de recurrencias
### Función potencia - versión 1
```python
def pot1(b,e): # e de tipo entero no negativo
    if e==0:
        return 1;
    else:
        return b*pot1(b,e-1)
```
$$T(n)=\begin{cases}3 & n=0\\ 5+T(n-1) & n>0\end{cases}$$
- n está relacionado con el tamaño del problema, aquí el exponente e.
- En el caso base se realizan 3 operaciones, y 5 en el recursivo (además del tiempo de otra llamada con parámetro n-1).

### Resolución por expansión de recurrencias
$T(n)=5+T(n-1)=5+5+T(n-2)=5\cdot2+T(n-2)=5+5+5+T(n-3)=5\cdot3+T(n-3)=\dots=5i+T(n-i)$
- Se llega al caso base T(0) cuando i=n.
- Sustituyendo: $T(n)=5n+T(0)=5n+3\in\Theta(n)$
- Tiene sentido: se decrementa n en cada llamada recursiva.

### Función potencia - versión 2
```python
def pot2(b,e): # e de tipo entero no negativo
    if e==0:
        return 1;
    elif e%2==0:
        return pot2(b*b,e//2)
    else:
        return b*pot2(b*b,e//2)
```
$$T(n)=\begin{cases}3 & n=0\\ 8+T(n/2) & n>0,\ n\text{ par}\\ 9+T((n-1)/2) & n>0,\ n\text{ impar}\end{cases}$$
- Función difícil de analizar, pero se puede suponer $n=2^x$ potencia de dos; el resultado del análisis es el mismo.

### Resolución por expansión de recurrencias
- Asumimos $n=2^x$ (por tanto par):
$T(n)=8+T(n/2)=8+8+T(n/4)=8\cdot2+T(n/2^2)=8+8+8+T(n/8)=8\cdot3+T(n/2^3)=\dots=8i+T(n/2^i)$
- ¿Cuándo se llega a T(0)? i→∞, no tiene sentido: el parámetro de T es entero.
- Se llega a T(1) cuando $n/2^i=1$, es decir $i=\log_2 n$.
- Sustituyendo: $T(n)=8\log_2 n+T(1)=8\log_2 n+9+T(0)=8\log_2 n+9+3=8\log_2 n+12\in\Theta(\log n)$
- Tiene sentido: se divide n por 2 en cada llamada recursiva.

### Soluciones generales a relaciones de recurrencia
- $T(n)=\begin{cases}a & n=0\\ b+T(n-1) & n>0\end{cases}$ ⇒ $T(n)=bn+a\in\Theta(n)$
- $T(n)=\begin{cases}a & n=1\\ b+T(n-1) & n>1\end{cases}$ ⇒ $T(n)=b(n-1)+a\in\Theta(n)$
- $T(n)=\begin{cases}a & n=1\\ b+T(n/2) & n>1\end{cases}$ ⇒ $T(n)=b\log_2 n+a\in\Theta(\log n)$
- $T(n)=\begin{cases}a & n=0\\ b+T(n/2) & n>0\end{cases}$ ⇒ $T(n)=b\log_2 n+b+a\in\Theta(\log n)$

#### $T(n)=\begin{cases}a & n=0\\ bn+c+T(n-1) & n>0\end{cases}$
$T(n)=bn+c+T(n-1)$
$=bn+c+b(n-1)+c+T(n-2)=2bn-b+2c+T(n-2)$
$=2bn-b+2c+b(n-2)+c+T(n-3)=3bn-b(1+2)+3c+T(n-3)$
$=3bn-b(1+2)+3c+b(n-3)+c+T(n-4)=4bn-b(1+2+3)+4c+T(n-4)$
$\dots=ibn-b\sum_{j=1}^{i-1}j+ic+T(n-i)=ibn+ic-b\frac{i(i-1)}{2}+T(n-i)$
- Se alcanza T(0) para i=n. Sustituyendo: $T(n)=bn^2-\frac b2 n(n-1)+cn+a$
- $T(n)=\frac b2 n^2+(c+\frac b2)n+a\in\Theta(n^2)$
- Tiene sentido: se hacen $n+(n-1)+(n-2)+\dots+1$ operaciones.

#### $T(n)=\begin{cases}a & n=0\\ bn+c+2T(n/2) & n>0\end{cases}$
$T(n)=bn+c+2T(n/2)$
$=bn+c+2\left[b\frac n2+c+2T(n/4)\right]$
$=bn+c+2\left[b\frac n2+c+2\left[b\frac n4+c+2T(n/8)\right]\right]$
$=3bn+c(1+2+4)+2^3T(n/2^3)=3bn+c(2^3-1)+2^3T(n/2^3)$
$\dots=ibn+c(2^i-1)+2^iT(n/2^i)$
- Se alcanza T(1) para $n/2^i=1$, es decir $i=\log_2 n$. Sustituyendo:
$T(n)=bn\log_2 n+c(n-1)+nT(1)=bn\log_2 n+c(n-1)+n(b+c+2T(0))=bn\log_2 n+cn-c+nb+nc+2na$
$T(n)=bn\log_2 n+(2c+b+2a)n-c\in\Theta(n\log n)$
- Tiene sentido: se hacen n operaciones $1+\log_2 n$ veces.

### Teorema maestro - versión simple
Fórmula útil para algoritmos "divide y vencerás":
$$T(n)=\begin{cases}d & n=1\\ aT(n/b)+cn^k & n>1\end{cases}$$
$$T(n)=\begin{cases}\Theta(n^k) & \text{si } a/b^k<1\\ \Theta(n^k\log n) & \text{si } a/b^k=1\\ \Theta(n^{\log_b a}) & \text{si } a/b^k>1\end{cases}$$

### Teorema maestro - demostración
$T(n)=aT(n/b)+cn^k$
$=a\left[aT\left(\frac n{b^2}\right)+c\left(\frac nb\right)^k\right]+cn^k=a^2T\left(\frac n{b^2}\right)+cn^k\left(1+\frac a{b^k}\right)$
$=a^2\left[aT\left(\frac n{b^3}\right)+c\left(\frac n{b^2}\right)^k\right]+cn^k\left(1+\frac a{b^k}\right)=a^3T\left(\frac n{b^3}\right)+cn^k\left(1+\frac a{b^k}+\frac{a^2}{b^{2k}}\right)$
$\dots=a^iT\left(\frac n{b^i}\right)+cn^k\sum_{j=0}^{i-1}\left(\frac a{b^k}\right)^j$
- Se alcanza T(1)=c cuando $i=\log_b n$:
$=ca^{\log_b n}+cn^k\sum_{j=0}^{\log_b n-1}\left(\frac a{b^k}\right)^j=cn^k\left(\frac a{b^k}\right)^{\log_b n}+cn^k\sum_{j=0}^{\log_b n-1}\left(\frac a{b^k}\right)^j$

### Teorema maestro - demostración (logaritmos)
- La última igualdad se debe a: $cn^k\left(\frac a{b^k}\right)^{\log_b n}=cn^k\frac{a^{\log_b n}}{b^{k\log_b n}}=cn^k\frac{a^{\log_b n}}{n^k}=ca^{\log_b n}$
- Más adelante también se necesita: $n^{\log_b a}=a^{\log_b n}$, ya que $\log_b n^{\log_b a}=\log_b a^{\log_b n}=\log_b a\cdot\log_b n$
- Finalmente: $T(n)=cn^k\sum_{j=0}^{\log_b n}\left(\frac a{b^k}\right)^j$
- Hay 3 casos según los valores de a, b y k.

### Teorema maestro - demostración (casos)
$T(n)=cn^k\sum_{j=0}^{\log_b n}\left(\frac a{b^k}\right)^j$
1. $a<b^k\Rightarrow T(n)\in\Theta(n^k)$. Como $\sum_{i=0}^{\infty}r^i=\frac1{1-r}$ = constante (no diverge) para r<1.
2. $a=b^k\Rightarrow T(n)\in\Theta(n^k\log n)$. $T(n)=cn^k(\log_b n+1)$
3. $a>b^k\Rightarrow T(n)\in\Theta(n^{\log_b a})$
$T(n)=cn^k\frac{\left(\frac a{b^k}\right)^{\log_b n+1}-1}{\frac a{b^k}-1}=\frac{cn^k\left(\frac a{b^k}\right)\frac{a^{\log_b n}}{n^k}-cn^k}{K_1}=\frac{K_2a^{\log_b n}-cn^k}{K_1}=\frac{K_2n^{\log_b a}-cn^k}{K_1}$
Como $a>b^k\Rightarrow\log_b a>k\Rightarrow T(n)\in\Theta(n^{\log_b a})$

### Teorema maestro - versión completa
Dada una recurrencia $T(n)=aT(n/b)+f(n)$ donde a>0, b>0 y f(n) asintóticamente positiva, se puede aplicar el teorema maestro en estos tres casos:
1. Si $f(n)=O(n^{\log_b a-\epsilon})$ para alguna constante $\epsilon>0$, entonces $T(n)\in\Theta(n^{\log_b a})$
2. Si $f(n)=\Theta(n^{\log_b a}\log^k n)$ con k≥0 (k suele ser 0), entonces $T(n)\in\Theta(n^{\log_b a}\log^{k+1}n)$
3. Si $f(n)=\Omega(n^{\log_b a+\epsilon})$ con $\epsilon>0$, y f(n) satisface la condición de regularidad ($af(n/b)\le cf(n)$ para alguna constante c<1 y para todo n suficientemente grande), entonces $T(n)\in\Theta(f(n))$

### Errores frecuentes - Expansión de recurrencias
- No comprobar que la fórmula final sea análoga a la recurrencia inicial (también al aplicar el método general).
- No realizar correctamente la primera expansión (muy frecuente).
- No simplificar: los patrones serán mucho más complicados.

## Análisis de eficiencia en tiempo: método general
- No siempre se puede aplicar la expansión de recurrencias. Para muchas recurrencias no se conoce la forma de resolverlas (como con integrales o ecuaciones diferenciales: se sabe resolver un subconjunto, no todas).
- El método general amplía el conjunto de recurrencias resolubles.

### Recurrencias homogéneas
- Recurrencia homogénea (aparece un 0 en la parte derecha): $a_0T(n)+a_1T(n-1)+\dots+a_kT(n-k)=0$
- Se buscan soluciones del tipo: $T(n)=C_1P_1(n)r_1^n+\dots+C_kP_k(n)r_k^n=\sum_{i=1}^{k}C_iP_i(n)r_i^n$
- Realizando el cambio $x^{z-n+k}=T(z)$ se obtiene la ecuación característica asociada: $a_0x^k+a_1x^{k-1}+\dots+a_{k-1}x+a_k=0$

### Primer caso: raíces distintas
- Si todas las raíces del polinomio de la ecuación característica son distintas: $T(n)=C_1r_1^n+\dots+C_kr_k^n=\sum_{i=1}^{k}C_ir_i^n$
- Las constantes $r_i$ son las raíces de la ecuación característica.
- $P_i(n)=1$, para todo i.
- Las constantes $C_i$ se hallan a partir de las condiciones iniciales, resolviendo un sistema de ecuaciones.

### Ejemplo: Números de Fibonacci
$$T(n)=\begin{cases}0 & n=0\\ 1 & n=1\\ T(n-1)+T(n-2) & n>1\end{cases}$$
- Ecuación característica $x^2-x-1=0$, raíces $r_1=\frac{1+\sqrt5}2$, $r_2=\frac{1-\sqrt5}2$
- Al ser distintas: $T(n)=C_1r_1^n+C_2r_2^n=C_1\left(\frac{1+\sqrt5}2\right)^n+C_2\left(\frac{1-\sqrt5}2\right)^n$
- Constantes a partir de condiciones iniciales (casos base):
  - $C_1+C_2=0=T(0)$
  - $C_1\frac{1+\sqrt5}2+C_2\frac{1-\sqrt5}2=1=T(1)$
- Resolviendo: $C_1=\frac1{\sqrt5}$, $C_2=-\frac1{\sqrt5}$
- Finalmente: $T(n)=\frac1{\sqrt5}\left(\frac{1+\sqrt5}2\right)^n-\frac1{\sqrt5}\left(\frac{1-\sqrt5}2\right)^n$
- El segundo término tiende a 0 según n→∞, por tanto $T(n)\in\Theta\left(\left(\frac{1+\sqrt5}2\right)^n\right)$
- El orden es exponencial. El árbol de recursión es binario pero está podado. Para un árbol binario completo el orden es $2^n$. Aquí la base del exponente es $(1+\sqrt5)/2\approx1.618<2$.
[figura: árbol de recursión de Fibonacci con raíz 7; cada nodo k>1 tiene hijos k-1 y k-2; hojas 1 y 0 (árbol podado)]

### Segundo caso: raíces con multiplicidad mayor que 1
- En general el polinomio de la ecuación característica puede tener raíces con multiplicidad 1 o mayor: $(x-r_1)^{m_1}(x-r_2)^{m_2}\cdots(x-r_k)^{m_k}=0$
- La solución tiene la forma: $T(n)=\sum_{i=1}^{m_1}C_{1i}n^{i-1}r_1^n+\sum_{i=1}^{m_2}C_{2i}n^{i-1}r_2^n+\dots+\sum_{i=1}^{m_k}C_{ki}n^{i-1}r_k^n$
- Ejemplo: $T(n)=5T(n-1)-8T(n-2)+4T(n-3)$
  - Ecuación característica: $x^3-5x^2+8x-4=(x-2)^2(x-1)=0$
  - El 2 es raíz doble, por tanto: $T(n)=C_12^n+C_2n2^n+C_31^n$

### Recurrencias no homogéneas - una primera idea
- La parte derecha ya no es 0: $T(n)-2T(n-1)=3^n$ (a)
- Se convierte en homogénea:
  - $T(n+1)-2T(n)=3^{n+1}$ (1)
  - $3T(n)-6T(n-1)=3^{n+1}$ (2)
  - $T(n+1)-5T(n)+6T(n-1)=0$ (1)-(2)
- En (1) se incrementa n en (a); en (2) se multiplica (a) por 3.
- Con T(0)=0 y T(1)=3: $T(n)=3\cdot3^n-3\cdot2^n\in\Theta(3^n)$

### Recurrencias no homogéneas - caso simple
- Un solo término a la derecha, donde d es el orden del polinomio P(n): $a_0T(n)+a_1T(n-1)+\dots+a_kT(n-k)=b^nP^d(n)$
- Ecuación característica: $(a_0x^k+a_1x^{k-1}+\dots+a_k)(x-b)^{d+1}=0$
- Ejemplo: $T(n)-2T(n-1)=n$, con $b=1$, $P(n)=n$, $d=1$
  - $(x-2)(x-1)^2=0\Rightarrow T(n)=C_12^n+C_21^n+C_3n1^n\in\Theta(2^n)$

### Recurrencias no homogéneas - caso general
- Recurrencia general: $a_0T(n)+a_1T(n-1)+\dots+a_kT(n-k)=b_1^nP_1^{d_1}(n)+\dots+b_s^nP_s^{d_s}(n)$
- Ecuación característica: $(a_0x^k+a_1x^{k-1}+\dots+a_k)(x-b_1)^{d_1+1}\cdots(x-b_s)^{d_s+1}=0$
- Ejemplo: $T(n)=2T(n-1)+n+2^n$ con $T(0)=1$
  - Ecuación característica: $(x-2)(x-1)^2(x-2)=(x-2)^2(x-1)^2=0$
  - Solución (sin hallar constantes): $T(n)=C_12^n+C_2n2^n+C_31^n+C_4n1^n$
- Dado T(0)=1, y usando $T(n)=2T(n-1)+n+2^n$, hay que hallar T(1), T(2), T(3) para formar un sistema de 4 ecuaciones con 4 incógnitas (las constantes): $T(1)=5$, $T(2)=16$, $T(3)=43$
  - $C_1+C_3=1=T(0)$
  - $2C_1+2C_2+C_3+C_4=5=T(1)$
  - $4C_1+8C_2+C_3+2C_4=16=T(2)$
  - $8C_1+24C_2+C_3+3C_4=43=T(3)$
- Solución final ($C_1=3$, $C_2=1$, $C_3=-2$, $C_4=-1$): $T(n)=3\cdot2^n+n2^n-2-n\in\Theta(n2^n)$

### Método de cambio de variable
- Recurrencia: $T(n)=4T(n/2)+n$, $T(1)=1$, $T(2)=6$
- Cambio $n=2^k\Rightarrow T(2^k)=4T(2^{k-1})+2^k$
- $T(n)=T(2^k)=t(k)\Rightarrow t(k)=4t(k-1)+2^k$ (nueva recurrencia)
- Ecuación característica: $(x-4)(x-2)=0$
- $t(k)=C_1(4^k)+C_2(2^k)=C_1(2^k)^2+C_2(2^k)$
- Deshaciendo el cambio: $T(n)=C_1n^2+C_2n$
- Hallando las constantes: $T(n)=2n^2-n\in\Theta(n^2)$

### Expansión de recurrencias (mismo ejemplo)
$T(n)=4T(n/2)+n$
$=4\left[4T\left(\frac n4\right)+\frac n2\right]+n=4^2T\left(\frac n{2^2}\right)+2n+n$
$=4\left[4\left[4T\left(\frac n8\right)+\frac n4\right]+\frac n2\right]+n=4^3T\left(\frac n{2^3}\right)+4n+2n+n$
$=4^iT\left(\frac n{2^i}\right)+n\sum_{j=0}^{i-1}2^j=4^iT\left(\frac n{2^i}\right)+n(2^i-1)$
- El caso base T(1) se alcanza cuando $n=2^i$; $n^2=(2^i)^2=(2^2)^i=4^i$. Sustituyendo: $T(n)=n^2+n(n-1)=2n^2-n$

### Errores frecuentes - método general
- Cambio de variable $n=2^k$ y ecuación $T(2^k)=4T(2^{k-1})+2^k$:
  - Error: al cambiar $t(k)=T(2^k)$ hacer $t(k)=4t(k-1)+k$
  - Correcto: $t(k)=4t(k-1)+2^k$
- Si $t(k)-t(k-1)=3^{2k}$ no hay una potencia del tipo $b^k$ en el miembro derecho. Hay que transformarla: $3^{2k}=(3^2)^k=9^k$
- Para hallar el polinomio característico hay que sacar factor común de las potencias en el miembro derecho:
  - $t(k)-t(k-1)=2+k^3+2^k+k2^k$ es $t(k)-t(k-1)=(2+k^3)1^k+(1+k)2^k$
  - El polinomio característico sería $(x-1)(x-1)^4(x-2)^2=(x-1)^5(x-2)^2$

## Análisis de eficiencia en espacio
### Modelo de memoria
Modelo (simple) de memoria, de arriba abajo: Pila / Subprogramas; Montículo (heap); Datos estáticos; Código.
- Código del algoritmo.
- Datos estáticos: variables globales.
- Llamadas a subprogramas (pila): parámetros, variables locales.
- Memoria dinámica (montículo).

### Árbol y proceso de llamadas a funciones
```
...
A(..)
...

def A(...)
    ...
    B(..)
    ...

def B(...)
    ...
    C(..)
    ...

def C(...)
    ...
```
- Árbol de llamadas: main -> A -> B -> C (cadena).
- Proceso de llamadas (orden): main; 1 llamada a A; 2 llamada a B; 3 llamada a C; 4 fin de C; 5 fin de B; 6 fin de A.

### Estado de la pila
Secuencia de estados de la pila (sobre datos dinámicos, datos estáticos, código): vacía -> A -> A,B -> A,B,C -> A,B -> A -> vacía.

### Árbol recursivo
- Caso recursivo: $F_{n+2}=F_{n+1}+F_n$. Casos base $F_1=F_2=1$.
```
F5
  F4
    F3
      F2
      F1
    F2
  F3
    F2
    F1
```

### Estado de la pila
Secuencia de estados de la pila para el cálculo de F5 (recorrido en profundidad del árbol anterior; la pila crece en cada llamada y decrece al retornar). Altura máxima de la pila: F5,F4,F3,F2 (4 niveles).
$$Espacio(n)\in\Theta(n)$$

### Llamadas a subprogramas
- La complejidad depende de la profundidad del árbol recursivo de llamadas (para ilustrarlo, los nodos de un mismo nivel se colorean igual).
- También depende de los recursos que requiera cada subprograma (función/método/subrutina) ejecutado:
  - Parámetros de los subprogramas
  - Variables locales a los subprogramas
  - Memoria dinámica reservada al ejecutar el subprograma
